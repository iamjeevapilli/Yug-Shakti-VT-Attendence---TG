🤖 WhatsApp Bot Setup Guide

Follow these simple, free steps to enable automated WhatsApp alerts for your attendance portal:

  1. Add the CallMeBot WhatsApp number to your contacts:
    +34 621 371 153
  2. Send the following message to that contact on WhatsApp:
    I allow callmebot to send me messages
  3. Wait 1-2 minutes. The bot will reply with your unique API Key.
  4. Copy that API Key and paste it into the CallMeBot API Key field in the settings.
💡 Note: This service is 100% free and sends instant notifications. Make sure the phone number in settings matches the WhatsApp account you use to request the key.

✈️ Telegram Bot Setup Guide

Follow these simple, free steps to create your own official Telegram bot for instant attendance alerts:

  1. Create the Bot:
    Open Telegram, search for @BotFather, start a chat, and send:
    /newbot
    Follow the prompts to name your bot and choose a username. Copy the long HTTP API Token it gives you.
  2. Get your Chat ID:
    Search for @GetChatID_Bot (or `@userinfobot`), start the chat, and copy the numeric Chat ID it sends you.
  3. Start your Bot:
    Search for your new bot's username on Telegram, open it, and click Start (this registers you to receive messages).
  4. Save in Settings:
    Paste the Bot Token and Chat ID into the fields in settings, check the Auto checkbox, and click Save Settings.
💡 Why this is awesome: This bot runs directly through Telegram's official API. It is completely private to you, delivers messages in milliseconds, and never gets rate-limited or blocked.
