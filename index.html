✈️ Telegram Bot Setup Guide

Follow these simple, free steps to create your own official Telegram bot for instant attendance alerts:

  1. Create the Bot:
    Open Telegram, search for @BotFather, start a chat, and send:
    /newbot
    Follow the prompts to name your bot and choose a username. Copy the long HTTP API Token it gives you.
  2. Get Chat ID (User or Group):
    • For yourself: Chat with @GetChatID_Bot and copy your ID.
    • For a Group (multiple friends): Create a Telegram group with your friends, add your bot as an admin, add @GetChatID_Bot to the group to get the group ID (starts with a minus, e.g., -10012345678), then remove the helper bot.
    • Multiple Chat IDs: You can enter multiple Chat IDs separated by commas (e.g. 12345678, 98765432, -10012345678).
  3. Start your Bot:
    Search for your new bot's username on Telegram, open it, and click Start (or send a message). If using a group, make sure the bot is added to the group and has permissions to post.
  4. Save in Settings:
    Paste the Bot Token and Chat ID(s) into the fields in settings, check the Auto checkbox, and click Save Settings.
💡 Why this is awesome: This bot runs directly through Telegram's official API. It is completely private to you, delivers messages in milliseconds, and never gets rate-limited or blocked.
